## 🚀 Quick Start

### VoiceStudio

```bash
cd VoiceStudio-Integrated

# Backend
pip install -r requirements.txt
python api_server.py

# Frontend (in another terminal)
cd frontend
npm install
npm run dev
```

Access at: `http://localhost:5173`

API Docs: `http://localhost:8000/docs`
